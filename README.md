# Pagina Fictícia AluraPlus
Projeto desenvolvido durante os estudos de HTML e CSS na plataforma Alura, com o objetivo de praticar a estruturação e a estilização de páginas web.

## Tecnologias utilizadas 
- HTML5
- CSS3
- Google Fonts (Inter)

## Conceitos praticados
- Estruturação de páginas com HTML;
- Estilização com CSS e variáveis personalizadas;
- Layouts com CSS Grid e Flexbox;
- Organização de elementos, espaçamentos e margens;
- Uso de imagens, links e efeitos de interação (*hover*).
